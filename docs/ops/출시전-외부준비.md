# 출시 전에 사장님(운영자)이 직접 해야 하는 일

1. 통신판매업 신고(정부24, 관할 구청) → 신고번호를 lib/operator.ts에.
2. 사업자 정보·개인정보 보호책임자·고객센터 연락처를 lib/operator.ts에 → 약관·처리방침 판 올리기.
3. 결제대행사(토스페이먼츠) 계약 → 결제 연결. 결제 기록 5년 보관 구현.
4. 위치정보 확인: '출근 위치 확인'은 좌표를 저장하지 않고 거리만 남기지만, 개인위치정보를 다루는 서비스인지 방송통신위원회 위치정보사업·위치기반서비스사업 신고 대상 여부를 변호사에게 확인. 필요하면 신고 전까지 기능을 끄기.
5. 약관·처리방침·운영정책·서식 법률 검토 → reviewed: true로 정식판.
6. GitHub Secrets(이메일·알림톡·카카오) 채우기.
7. 개인정보 보호 교육 수강, 내부 관리계획 승인(docs/ops/개인정보-내부관리계획.md).
8. 광고: 메타 픽셀을 켰다면 처리방침 10항 유지, 광고 문구에 '30일 무료' 등 사실만.
