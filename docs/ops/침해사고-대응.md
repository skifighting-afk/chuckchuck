# 개인정보 유출·침해사고 대응 절차 (초안)

## 1. 알게 된 순간 (0~1시간)
1. 피해가 커지지 않게 막는다: 의심 계정 로그아웃·정지, API 키·웹훅 끄기, 비밀값 교체(Supabase·GitHub Secrets).
2. 기록을 지우지 않는다: 접속 기록·변경 이력·서버 로그를 따로 저장한다.
3. 서비스 상태 화면에 장애·점검 안내를 올린다(운영자 화면 → 장애 공지).

## 2. 확인 (24시간 안)
- 언제, 어떤 정보(항목), 몇 명, 어떻게 새었는지 정리한다.
- 가게(사장님) 데이터라면 해당 사장님께 먼저 알린다(처리위탁 조건 ⑤).

## 3. 통지·신고 (알게 된 때부터 72시간 안)
- 정보주체에게 알린다(개인정보 보호법 제34조): 앱 알림 + 화면 안내, 연락 가능한 경우 이메일·문자.
- 1천 명 이상이거나 민감정보·고유식별정보, 외부 해킹이면 개인정보보호위원회·한국인터넷진흥원(118)에 신고한다.

### 알림 문안
> [척척사장] 개인정보 유출 안내
> - 무엇이: (항목)
> - 언제·어떻게: (시점과 경위)
> - 우리가 한 일: (막은 조치)
> - 하실 일: 비밀번호 바꾸기, 2단계 인증 켜기, 의심 연락 주의
> - 문의: 앱 문의하기(종류: 계정·개인정보), 보호책임자 (연락처)
> - 피해 구제: 개인정보침해신고센터 118, 개인정보 분쟁조정위원회 1833-6972
