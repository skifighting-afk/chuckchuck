# 문의·불만·환불 처리 절차

| 종류 | 받는 곳 | 기한 | 담당이 할 일 |
|---|---|---|---|
| 일반 문의 | 앱 문의하기 | 첫 답 3영업일 | /admin#support에서 답변, 필요하면 도움말(lib/faq.ts)에 추가 |
| 오류·장애 | 문의하기(오류·문제), 서버 오류 알림 | 바로 확인 | 재현 → 고침 → 배포, 영향 크면 /status 장애 공지 |
| 환불 신청 | 문의하기(환불 신청) | 3영업일 | 해지·환불 규정(/refund) 공식으로 계산 → 결제 취소 → 결과 답변 |
| 개인정보 요청 | 문의하기(개인정보 요청), /privacy-request | 10일 | 본인 확인(로그인 계정) → 열람·정정·삭제·정지 처리 → 기록 3년 |
| 신고(게시물·행동·보안) | 문의하기(신고), security.txt | 3영업일 | 운영정책 3항 단계에 따라 조치, 신고자 정보는 알리지 않음 |
| 이용 제한 이의 | 문의하기 | 7일 | 다시 검토해 답변 |

해결이 어려우면 처리 계획과 예상 일정을 먼저 알린다. 끝나지 않는 분쟁은 한국소비자원(1372)·전자거래분쟁조정위원회 안내.
