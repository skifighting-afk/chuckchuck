# 실기기 QR 출퇴근 점검표 (작업 052)

자동 점검(`npm run e2e`)은 아이폰 13·픽셀 7 화면 크기로 **QR 링크로 열기**와 **QR 사진 읽기**를 확인한다.
카메라 실시간 촬영은 에뮬레이터로 확인할 수 없으니, 큰 화면 변경이 있을 때 실제 휴대폰으로 아래를 한 번씩 확인한다.

준비: 사장님 계정으로 출퇴근 기록 → 출퇴근 QR → "QR 이미지 저장" 후 인쇄(또는 다른 화면에 띄우기). 직원 계정 하나.

| # | 확인할 것 | 아이폰 (Safari) | 안드로이드 (Chrome) | 삼성 인터넷 |
|---|---|---|---|---|
| 1 | 기본 카메라 앱으로 QR을 찍으면 척척사장봇 출근 화면이 열린다 | | | |
| 2 | 로그인이 풀려 있으면 로그인 후 원래 출근 화면으로 돌아온다 | | | |
| 3 | "휴대폰 카메라로 연 QR 확인하기" → "출근 기록하기"로 출근된다 | | | |
| 4 | 앱 안 "카메라로 QR 찍기": 카메라 권한 요청이 뜨고, 허용하면 QR을 읽는다 | | | |
| 5 | 카메라 권한을 거부하면 "QR 사진 읽기" 안내가 보인다 | | | |
| 6 | "QR 사진 읽기"로 갤러리의 QR 사진을 골라 출근된다 | | | |
| 7 | 다른 가게 QR·예전 QR(새로 만들기 전)은 기록되지 않는다 | | | |
| 8 | 퇴근도 같은 방법으로 된다, 휴게 시작·끝 버튼이 눌린다 | | | |
| 9 | 화면이 가로로 넘치지 않고 버튼이 손가락으로 누르기 쉽다(48px) | | | |
| 10 | 어두운 매장·형광등 반사에서도 2~3초 안에 읽힌다(인쇄 크기 8cm 이상 권장) | | | |
