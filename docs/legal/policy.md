## 1. 목적

이 정책은 이용약관 제9조(회원의 의무)를 구체적으로 정해, 모든 사장님과 직원이 안전하게 쓰도록 돕습니다.

## 2. 하지 말아야 할 일

- 다른 사람의 계정으로 로그인하거나 계정을 여러 사람이 나눠 쓰기

- 직원이 아닌 사람의 개인정보를 넣거나, 직원 동의 없이 근무와 관계없는 정보(주민등록번호·건강 상세 등)를 메모·사진에 남기기

- 다른 직원 대신 출퇴근 찍기, 출퇴근·급여 기록을 사실과 다르게 꾸미기

- 공지·매뉴얼·매장 일지·메시지에 욕설, 성희롱, 차별, 개인 신상 공개, 불법 정보 올리기

- 자동 프로그램으로 화면을 반복 호출하거나, 오픈 API 키를 공유·공개하거나, 보안 장치를 우회하기

- 서비스를 베껴 다시 팔거나, 서비스를 이용해 법령에 어긋나는 근로조건(최저임금 미만 등)을 강요하기

## 3. 이용 제한 단계

| 단계 | 언제 | 조치 |
|---|---|---|
| 안내 | 처음이거나 가벼운 위반 | 앱 안 안내와 함께 고칠 기회를 드려요 |
| 일부 제한 | 안내 뒤에도 반복 | 해당 기능(공지·메시지·API 등)을 7일 동안 막아요 |
| 이용 정지 | 다른 사람에게 피해가 크거나 법령 위반 | 계정을 30일 동안 정지해요. 가게 데이터 내려받기는 계속 할 수 있어요 |
| 계약 해지 | 정지 뒤에도 반복하거나 범죄에 쓰인 경우 | 이용계약을 끝내요. 남은 기간 요금은 환불 규정에 따라 돌려드려요 |

다른 회원이 바로 피해를 입는 급한 경우에는 먼저 막고 바로 알려 드려요. 제한할 때는 사유·기간·이의 제기 방법을 함께 알려요.

## 4. 신고와 이의 제기

문제가 있는 글·사진·행동은 앱의 문의하기(종류: 기타)로 신고해 주세요. 신고한 사람의 정보는 상대에게 알리지 않아요.

이용 제한에 동의하지 않으면 알림을 받은 날부터 14일 안에 문의하기로 이의를 제기할 수 있고, 회사는 7일 안에 다시 검토해 답해요.

## 5. 문의·불만 처리

| 단계 | 기한 |
|---|---|
| 접수 확인 | 바로(앱 안 문의 번호) |
| 첫 답변 | 3영업일 안 |
| 환불·개인정보 요청 처리 | 환불 3영업일, 개인정보 열람·정정·삭제 10일 안 |
| 해결이 어려울 때 | 처리 계획과 예상 일정을 먼저 알려요 |

운영 시간: 평일 10:00~18:00(점심 12:00~13:00, 주말·공휴일 제외). 그 밖의 시간에 남긴 문의는 다음 영업일에 확인해요. 서비스 장애는 시간과 관계없이 서비스 상태 화면(/status)에 알려요.

회사와 해결되지 않는 분쟁은 한국소비자원(1372) 또는 전자거래분쟁조정위원회(ecmc.or.kr)에 조정을 신청할 수 있어요.
