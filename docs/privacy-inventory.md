# 개인정보 처리 목록 (작업 070)

척척사장봇이 실제로 저장하는 개인정보를 코드 기준으로 정리한 것. 개인정보처리방침(작업 015)과 처리위탁 조항(작업 017)의 근거로 쓴다.
코드가 바뀌면 이 문서도 같이 고친다. 기준일: 2026-10-05. 개인정보 처리방침 본문은 `lib/legal-docs.ts`(→ `docs/legal/privacy.md`)에 있고, 이 목록과 맞춰 고친다.

## 누가 처리자인가
- **사장님(가게)** 이 직원 개인정보의 처리자다. 척척사장봇은 사장님의 위탁을 받아 처리하는 **수탁자**다 (개인정보 보호법 제26조).
- **사장님·직원 본인의 계정 정보(이메일, 이름, 비밀번호)** 는 척척사장봇이 직접 처리자다.

## 저장 위치
| 위치 | 내용 | 비고 |
|---|---|---|

| `attendance_records` | 직원별 출퇴근 시각·휴게(가게별 한 건 한 행, 작업 045). 화면에는 최근 400일과 확정 해제 중인 달만 보냄 | 3년 보존 서류. 내려받기에는 전체 |
| `contract_envelopes`, `contract_events` | 근로계약서 본문 스냅샷(직원 성명·주소·연락처·임금·근로조건), 양측 서명 기록(이름, 이메일, 시각, 확인 방식) | 서명 후 변경 불가 |
| `payslip_documents` | 임금명세서 본문(성명, 직원번호, 임금·공제 내역) | 보낸 뒤 변경·삭제 불가 |
| `document_activity` | 명세서·계약서 열람·내려받기·저장 확인 시각 | |

| `shift_records` | 근무표 한 칸씩(직원 ID, 날짜, 시각) — `stores.data` 근무표의 조회용 사본 | 가게 삭제 시 함께 삭제 |

| `payments` | 결제 금액·요금제·기간·상태·결제 수단 종류·영수증 주소·결제 시각(카드번호 없음) | 전자상거래법 5년. 가게 삭제 때도 남김 |
| `push_subscriptions` | 알림 받을 기기의 구독 주소와 암호화 키, 계정 ID | 알림을 끄거나 기기가 410/404를 돌려주면 삭제 |
| `hq_access_log` | 본사(운영자)가 가게를 열어 본 기록(누가, 언제, 어느 가게) | 1년 지나면 삭제 |
| `accountant_shares` | 세무사 링크(토큰 해시만), 대상 급여 달, 만료·끈 시각, 열람 시각 | 링크로 보는 자료는 사장님이 고른 달의 확정 급여(성명·직원번호·지급·공제) |
| `support_tickets` | 문의 종류·내용·본사 답변, 문의한 계정 ID와 가게 | 3년(전자상거래법 소비자 불만·분쟁 기록) |

## 저장하지 않는 것
주민등록번호, 계좌번호, 카드번호, 위치(GPS), 사진(증빙 파일 제외), 신분증.

## 누가 볼 수 있나 (서버에서 확인)
- 사장님: 자기 가게 전체
- 중간관리자: 위임받은 권한의 소속 지점 범위
- 직원: 본인 출퇴근·근무표·급여·계약·증빙만 (`lib/personal-team.ts`)
- 본사(운영자): 가게별 집계(직원 수, 요금제, 확인할 일 개수)만. 직원 개인정보와 계약서는 보지 않음 (`lib/admin-overview.ts`)

## 보관 기간 (현재 코드 기준과 정할 것)
- 휴가 증빙: 30일 (자동 삭제 동작)
- 근로계약서·임금명세서·출퇴근 기록: 근로기준법 제42조에 따라 사장님이 3년 보존해야 하는 서류. 사장님 탈퇴 시 최근 7일 안에 전체 데이터를 내려받아야 탈퇴를 예약할 수 있고, 예약 30일 뒤 가게 데이터·서류·계정을 모두 삭제한다(작업 056, `app/withdraw-api.ts`, `purge_store()`).
- 직원 탈퇴: 로그인 계정과 `app_users` 행은 바로 삭제, 가게와의 연결(`_members`)만 끊는다. 가게 쪽 근무·급여 기록과 계약서는 사장님 보존 서류로 남는다.
- `account_deletions`: 탈퇴 예약·완료 기록(계정 ID, 예약·삭제 시각). 이메일·이름은 담지 않는다.
