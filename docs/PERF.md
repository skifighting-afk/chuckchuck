# 응답 속도 측정 (작업 082)

측정: 로컬 Postgres, 가게 3,000곳(가게마다 직원 6명 기본 데이터), 같은 질의 20회 평균.

| 질의 | 쓰는 곳 | 전 | 후 |
|---|---|---|---|
| 직원 계정 → 소속 가게 찾기 | 직원·매니저의 모든 요청(resolveStore), 탈퇴 확인 | 340.4ms | 0.6ms |
| 가게 코드 → 가게 찾기 | 직원 가입 미리보기·신청 | 325.4ms | 0.7ms |
| 내 가입 신청 찾기 | 직원 가입 화면 | (같은 방식의 전체 훑기) | 색인 사용 |
| 대표 변경 받는 이메일 | 새 계정 첫 화면 | (전체 훑기) | 색인 사용 |

방법: 가게 데이터(JSON)의 `_members`·`_joinCodes`·`_joinApplications`에 GIN 식 색인(`jsonb_path_ops`),
질의를 `jsonb_array_elements` 전체 훑기에서 `@>` 포함 검사로 바꿈(supabase/migrations/20261005050000_store_lookup_indexes.sql).
사장님 본인 가게 찾기(`owner=?`)는 원래 기본 키라 빠름.
