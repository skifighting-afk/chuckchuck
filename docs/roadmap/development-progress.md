공통 권한 20개, 수명·내보내기 61개, 상태형 데모 19개까지 합계 236개 검증을 통과했다. 추가로 최종 리뷰 회귀 시험 9개 시나리오를 통과했다. 기능별 표의 합계 항목을 중복 집계하지 않는다.

화면: 360·390·768·1280px와 큰 글씨의 57개 상태에서 가로 넘침 없음. 실제 서버 저장·재조회, 직원/담당자 공개 범위, 두 탭 동시 수정의 409 입력 보존→최신 내용 확인→재저장을 직접 확인했다. 데모는 예시 데이터 안에서 동작하며 실제 API POST를 보내지 않는다.

독립 최종 리뷰에서 중요한 지적 7개를 모두 재현 시험의 실패→통과로 수정했다. 탈퇴·익명화 정리, 다른 직원 기록 보존, 교육 담당자 권한, 읽기 전용 내보내기, 면담 참여자 제한, 변경 이력, 상담 알림을 보완했다. 추가로 재연결 계정 권한과 중첩 기록 정리를 검증했다. 보류한 경미 지적은 없다.

키보드 이동·포커스 표시, 503 복구, 느린 통신의 중복 저장 방지, 실패한 최신 조회에서 입력 보존·정확한 오류 표시·재조회 후 입력칸 포커스 복구를 직접 확인했다. 실제 PostgreSQL에 복구한 입력을 저장·재조회했다.

GitHub 연결 도구의 403은 PC에 이미 등록된 GitHub 계정 인증을 명시해 해결했다. 새 인증 권한을 만들지 않고 HR 브랜치를 업로드하고 PR #15를 연결했다. 최신 main의 커밋된 시작 가이드도 충돌 없이 통합했다.

첫 Linux CI에서 전체 테스트·빌드·서버 함수 검사·급여/계약 커버리지는 통과했다. 화면 E2E의 기존 핵심 흐름 22개 및 HR 채용·교육·숙련도·희망/편성·면담 흐름은 통과했다. 상담 접수 후 동의 체크가 초기화되어 버튼이 비활성화되는 정상 상태를 기다림 오류로 판정한 테스트를 고쳤다. 저장·재조회 완료는 별도 접근성 처리 중 상태로 기다린다.

담당자 설정에서 503 재조회가 입력을 지우는 문제도 브라우저에서 재현→수정→복구 확인했다. 통신 오류에는 입력을 유지하고 401/403에는 기존처럼 접근 화면을 차단한다. 이 흐름을 E2E에 추가했다.

남은 게이트: 최종 커밋의 전체 Linux CI·E2E·자동 모바일 재검증, 운영 DB→서버→health→화면 배포와 배포 SHA 확인. 운영 점검은 새로 만든 빈 점검 매장에서 HR API를 읽기만 확인하고 비로그인 접근 차단을 검증한다. 실제 직원 기록에 시험 상담·알림을 만들지 않는다.

최종 변경 후 타입 검사·빌드·서버 함수 검사는 통과했다. 로컬 전체 npm test는 모든 HR 및 check-improve2까지 통과한 뒤 기존 check-secrets의 Windows spawnSync git EPERM에서 중단됐다. 동일 비밀정보 검사 알고리즘으로 698개 파일을 별도 검사해 통과했지만 전체 npm test 통과로 대체하지 않는다. E2E·자동 모바일은 Playwright 미설치로 실행되지 않았다. 기존 결제 29개·네이티브 25개 회귀는 개별 실행으로 통과했다.

이전 요금·시작 안내 변경은 stash와 별도 백업에 보존했고 이번 HR 변경에 섞지 않았다. 이전 홈페이지 100개·앱 100개 제안의 전체 실행 완료를 뜻하지 않는다.
