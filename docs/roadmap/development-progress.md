화면: 360·390·768·1280px와 큰 글씨의 57개 상태에서 가로 넘침 없음. 실제 서버 저장·재조회, 직원/담당자 공개 범위, 두 탭 동시 수정의 409 입력 보존→최신 내용 확인→재저장을 직접 확인했다. 데모는 예시 데이터 안에서 동작하며 실제 API POST를 보내지 않는다.

남은 게이트: 전체 코드 리뷰와 지적 수정, Linux CI의 전체 테스트·E2E·모바일 검증, HR 전용 PR, 운영 DB→서버→health→화면 배포와 배포 SHA 확인. 키보드·느린 통신·기존 근태/급여/계약 회귀 전체 확인도 완료 증거를 별도로 남긴다.

로컬 전체 npm test는 기존 check-secrets의 Windows spawnSync git EPERM에서 중단됐다. E2E·자동 모바일은 Playwright 미설치로 실행되지 않았다. 이를 통과로 표시하지 않는다. 타입 검사·빌드·서버 함수 검사는 통과했고 최종 변경 후 다시 확인한다.

이전 요금·시작 안내 변경은 stash와 별도 백업에 보존했고 이번 HR 변경에 섞지 않았다. 이전 홈페이지 100개·앱 100개 제안의 전체 실행 완료를 뜻하지 않는다.
