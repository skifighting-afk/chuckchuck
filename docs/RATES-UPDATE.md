# 해마다 바꿀 급여 기준 (작업 030)

`lib/pay-rules.ts`의 `RATES`에 해마다 새 연도를 추가한다. 없으면 급여 화면에 "요율 미등록" 경고가 뜨고,
그해 1월부터는 `npm test`가 실패해서 배포가 멈춘다. 12월에는 CI 로그에 미리 알림(WARN)이 찍힌다.

| 항목 | 보통 발표 시기 | 확인할 곳 |
|---|---|---|
| 최저임금(시급) | 매년 8월 5일 고시, 다음 해 1월 1일 적용 | 최저임금위원회, 고용노동부 고시 |
| 국민연금 보험료율 | 법 개정 시 (2026년부터 매년 0.5%p씩 인상 예정) | 국민연금공단 |
| 국민연금 기준소득월액 상·하한 | 매년 7월 1일 변경 | 국민연금공단 (현재 앱은 상·하한 미적용, 화면에 안내) |

| 장기요양보험료율 | 전년 11월 무렵 보건복지부 발표 | 보건복지부 (건강보험료 대비 비율 = 장기요양률 ÷ 건강보험료율) |
| 고용보험(실업급여) 근로자 부담 | 법 개정 시 | 고용노동부 |

## 순서
1. 위 기관 발표 자료로 숫자를 확인하고, 출처와 기준일을 `RATES` 위 주석에 적는다.
2. `RATES`에 `{pension, health, care, employment, minimumWage}`를 추가한다(근로자 부담분, 소수).
3. `scripts/check-pay-rules.mjs`에 새 연도 금액 점검(예: 2,000,000원 기준 각 보험료)을 추가한다.
4. `npm test` 통과 후 커밋한다: `작업: YYYY년 급여 요율 반영`.

2026년 값: 국민연금 4.75%, 건강보험 3.595%, 장기요양 건강보험료의 13.14%(0.9448% ÷ 7.19%), 고용보험 0.9%, 최저시급 10,320원.

## 근로기준 안내도 함께 (작업 098)
- `lib/labor-guide.ts`의 `LABOR_GUIDE_YEAR`를 새 해로 바꾸면 최저임금·4대보험 안내 문구가 RATES의 숫자로 바뀐다.
- 공식 링크가 열리는지 확인하고 `LABOR_GUIDE_CHECKED`를 확인한 날로 바꾼다.
- 점검(`check-pay-rules`)이 안내 숫자와 급여 계산 요율이 같은지 확인한다.

## 근로소득 간이세액표 (작업 023)
1. 새 해 표가 고시되면(소득세법 시행령 별표2 개정) 공식 PDF 주소로 Actions → "공식 자료 가져오기" 실행(name: `income-tax-YYYY`).
2. `data-import` 브랜치의 `income-tax-YYYY.txt`를 읽어 `data/income-tax-YYYY.json`으로 변환(구간 연속·세액 단조 증가 확인, 2026년은 646구간).
3. `lib/income-tax.ts`의 `TABLES`에 연도 추가, 1천만원 초과 구간 식·자녀 공제액도 별표 1~4호 문구대로 확인.
4. `check-pay-rules`에 표 값 몇 개를 그대로 넣어 점검.
