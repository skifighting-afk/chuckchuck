## 2. 내일 할 일 (사장님)

순서대로 하면 된다. 끝나면 Claude에게 "○○ 끝"이라고 알리기.

- [ ] **① Firebase 프로젝트**(무료, 5분) — console.firebase.google.com
  - 프로젝트 `chukchuk`(애널리틱스 끄기) → 안드로이드 앱 `kr.chukchukapp.app` → **google-services.json** 받기
  - 프로젝트 설정 → 서비스 계정 → **새 비공개 키(JSON)** 받기
  - GitHub Secrets에 `GOOGLE_SERVICES_JSON`, `FCM_SERVICE_ACCOUNT`로 넣기(파일 내용 전체, 채팅으로 보내지 않기)
- [ ] **② 구글 플레이 콘솔 가입**(개인, 25달러) — play.google.com/console/signup → 신원 확인(1~3일)
- [ ] **③ 애플 개발자 가입**(개인, 연 99달러) — 아이폰 'Apple Developer' 앱에서 Enroll → 승인(1~2일)
- [ ] **④ 통신판매업 신고** — 정부24 또는 구로구청 → 번호 받으면 알려 주기
- [ ] **⑤ 토스페이먼츠 가입 진행** — 사업자 정보·홈페이지(chukchukapp.kr) 그대로 사용 → 키 받으면 테스트 키부터 `TOSS_CLIENT_KEY`·`TOSS_SECRET_KEY`
- [ ] (시간 되면) 안드로이드 폰에 시험용 APK 설치해 써 보기 — GitHub → Actions → 앱 빌드 → 최근 실행 → `android-test-apk`
- [ ] (시간 되면) 비공개 테스트 테스터 12명 모으기(구글 정식 출시 조건: 12명 × 14일)
