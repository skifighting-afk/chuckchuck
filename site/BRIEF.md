# 척척사장 브랜드 홈페이지 — 크리에이티브 브리프 (2026-10)

이 폴더(`site/`)가 chukchukapp.kr 첫 화면(`/`)이다. 앱 화면(`/app`, `/signup`, `/demo` …)은 그대로 `app/`에서 나온다.
요금·최저임금·계산식·사업자 정보는 `lib/plans.ts`, `lib/labor-estimate.ts`, `lib/operator.ts`를 그대로 불러 쓴다(숫자를 홈페이지에 따로 적지 않는다).

## 01–06 시장 · 고객 · 목표 · 경쟁 · 포지셔닝 · USP

- 고객: 직원 2~15명인 식당·카페·소매점 사장님. 결정자도, 실무자도 사장님 한 명. 60~70대 사장님도 혼자 이해해야 한다.
- 지금 쓰는 도구: 종이 출근부, 단톡방 근무표 사진, 휴대폰 메모, 엑셀, 계산기, 서랍 속 종이 계약서. 월급날 전날 밤에 이걸 합친다.
- 고객 심리: "틀리면 직원이랑 얼굴 붉힌다"(관계 불안) > "노무 문제 생길까"(법 불안) > "귀찮다"(시간).
- 전환 목표(Primary): **30일 무료 체험 시작** (`/signup?role=owner&plan=…`). 보조: 가입 없이 예시 가게 눌러보기(`/demo`). 메타 광고 목표와 같다.
- 경쟁: 알밤, 시프티, flex mini, 매니지, 바니마니, 알파요 등. 대부분 앱 설치 + 직원 수 과금 또는 기능 나열형 랜딩.
- 포지셔닝: **사장님과 직원이 둘 다 확인하는 가게 장부.** 앱 설치 없이 링크로 열고, 직원 수 제한 없이 지점 수로만 낸다.
- USP 3개
  1. ✓✓ 양쪽 확인 — 출근은 직원이 찍고 사장님이 확인, 계약서는 사장님이 먼저·직원이 다음에 서명, 정정은 사장님 승인 뒤 반영.
  2. 설치 없음 — 휴대폰 브라우저로 열고, 직원은 가입 링크·가게 코드로 합류.
  3. 직원 수 무제한 · 월 9,900원부터(VAT 포함, 1지점) · 30일 무료 · 카드 등록 없음.

## 07 Big Idea ×3

- **A — 밤 11시의 출근부**: 월급날 전날 밤, 손글씨 출근부·포스트잇·계산기가 흩어진 책상. 스크롤하면 칸마다 체크가 찍히며 정리되고, 마지막에 급여 합계가 나온다.
- **B — ✓✓ 두 번의 체크**: 척척 = 체크 두 번. 하나는 직원이, 하나는 사장님이. 사이트 전체가 "누가 먼저 체크하고 누가 다음에 체크하나"의 짝으로 설명된다.
- **C — 가게의 하루 한 줄**: 07시 오픈부터 23시 마감까지 한 줄 타임라인. 스크롤이 시계가 된다.

**선택: B를 뼈대로, A를 히어로 장면으로.** B는 제품이 실제로 일하는 방식(양쪽 확인)을 그대로 보여 주고, 로고(이중 체크)와 캐릭터(머리 위 체크 두 개)와 이미 같은 모양이라 브랜드 자산이 쌓인다. A는 첫 화면에서 "이거 내 얘기네"를 만든다. C는 근무표 데모 안에 일부만 쓴다.

## 08–11 컨셉 · 은유 · 아트디렉션 · 시그니처

- 은유: **장부(ledger)**. 크림색 종이, 옅은 괘선, 손글씨(혼란) → 정자체 숫자(정리).
- 시그니처: **라임색 ✓✓ 획**. 히어로 체크 도장, 섹션 구분선 끝, 데모의 확인 짝, 버튼 아이콘, 결과 카드 도장, 최종 장면. 로고를 지워도 ✓✓와 괘선으로 알아본다.
- 색: 잉크 그린 `#0f3d2f` · 브랜드 그린 `#12634b` · 라임 `#d4f77d` · 장부 크림 `#f5f1e6` · 괘선 `#e2dac7` · 빨간 펜 `#c8452f`(혼란 장면에만).
- 글꼴: Pretendard(정리된 모든 글, 숫자는 tabular) + Nanum Pen Script(손글씨 출근부·메모에만). 손글씨 → 정자체로 바뀌는 것 자체가 이야기.
- 모양: 종이 모서리 4px, 휴대폰 화면 28px. 그림자는 종이가 책상에 놓인 느낌(아래로 길고 옅게).
- 캐릭터: 척척이(크림 몸·초록 앞치마·라임 체크). 안내자 역할만, 결정 순간(최종 CTA)에만 크게.

## 12 Hook 후보 (30개 중 추림)

손실: "월급 하나 틀리면 1년 단골 직원이 나가요" · 시간: "월급날 전날 밤 11시, 아직 계산기 두드리세요?" · 귀찮음: "단톡방에 '다음 주 근무표 언제 나와요?' 그만" · 결과: "찍으면 출근, 누르면 월급." · 비교: "출근부 종이 한 장 값보다 싸요" · 정체성: "사장님은 장사만 하세요" · 반전: "출근부는 직원이 쓰게 하세요" · 새 카테고리: "둘이 같이 쓰는 가게 장부" · 호기심: "체크 두 번이면 월급이 나와요" · Before/After: "9월 출근부, 손으로 쓰던 마지막 달"
→ **선택: "찍으면 출근, 누르면 월급."** 제품 작동 방식을 7글자 두 줄에 담고, ✓✓(찍기·누르기 두 동작)와 맞는다. 브랜드 문장 "직원 출근부터 월급 정리까지, 척척."은 그 아래 설명으로 둔다.

## 13–15 히어로 · 모션 스토리보드 · 판매 흐름

히어로(스크롤 고정 3.2화면):
- 0초: 크림 장부 위 손글씨 "9월 출근부". 직원 5명 × 14일 칸에 "9-6", 빨간 펜 수정("10시→11시"), 물음표. 포스트잇 3장("준호 대타??", "주휴수당 어떻게 계산?", 계산기 "1,284,5…"), 카톡 말풍선("사장님 저 내일 2시간 늦어요ㅠ"). 장부는 책상 위에 비스듬히(rotateX 24°, rotateZ −5°), 마우스를 따라 아주 살짝 기운다.
- 0.6초: 제목 "찍으면 출근, / 누르면 월급."이 아래에서 올라오고, 끝에 라임 ✓✓ 획이 그려진다.
- 스크롤 0→45%: 칸이 줄마다 ✓✓ 도장으로 바뀌고 손글씨가 정자체 시각으로 바뀐다. 포스트잇은 체크가 찍힌 뒤 하나씩 떨어져 나간다. 왼쪽 문구가 "누가 일했는지 ✓ → 몇 시간 일했는지 ✓ → 얼마 줄지 ✓✓"로 넘어간다.
- 45→75%: 장부가 똑바로 서며(기울기 0) 휴대폰 화면 크기로 줄어들고, 줄 끝에 직원별 급여가 차례로 계산된다.
- 75→100%: 아래에서 "이번 달 예상 급여" 카드가 올라와 합계가 세어진다. 버튼 "급여 확정 ✓✓". 모든 숫자에 '예시' 표시.
판매 흐름(감정): 공감(히어로) → 맞춤(우리 가게는?) → 이해(✓✓ 제품 둘러보기) → 놀람(30초 QR) → 사람(직원 쪽 화면, 단톡방 비교) → 쓸모(인건비 계산, 공유) → 확신(요금 계산) → 안심(걱정 다섯 가지) → 결말(장부가 다 체크된 9월).

## 19 증거 원칙

후기·고객 수·절감률·수상은 없다. 증거는 **제품 화면 그 자체**, 실제 요금 계산, 실제 계산식(근로기준법 제55조 주휴), 하지 않는 일 공개, 해지 일할 환불.
예시 화면에는 모두 "예시" 표시. 실제 고객 후기가 생기면 5번 섹션 옆에 원문 그대로 추가.

## 23 모션 문법

- 들어올 때: 아래 16px → 0, 투명 → 선명, 0.6초, cubic-bezier(.2,.8,.2,1).
- 체크: 획 그리기(stroke-dashoffset) 0.35초씩, 두 번째 획은 0.12초 뒤. 모든 확인 순간에 같은 박자.
- 숫자: 0부터 세지 않고 앞자리부터 굴러 멈춘다(0.8초).
- 버튼: 커지지 않는다. 누르면 ✓✓ 획이 그려지고 이동.
- 움직임 줄이기 설정이면 모두 최종 상태로 바로 보인다.

## 31–32 결말 · 걱정 다섯 가지

## 36–40 성능 · 접근성 · SEO · 분석

- 외부 요청 없음(글꼴도 우리 도메인). 자바스크립트 하나, 그림은 webp 하나. 3D 라이브러리 없이 CSS 원근으로.

## 47 자체 검수 질문

- 스크롤 녹화를 릴스에 올리면 멈춰 보는가 → 장부가 체크되며 휴대폰이 되는 장면.
- 캡처 한 장으로 알아보는가 → 크림 괘선 + 라임 ✓✓.
- 글을 반 지워도 이해되는가 → 손글씨 장부가 체크되고 급여가 나온다.
- 지어낸 숫자·후기가 있는가 → 없어야 한다. 예시 표시 확인.
