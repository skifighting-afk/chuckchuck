# 척척사장봇 — 멀티페이지 공식 홈페이지

## 1. Project Description
- 브랜드: 척척사장봇 (제품 별칭 "척척이", 한국어 B2B SaaS). 영문 브랜드명 사용하지 않음
- 포지셔닝: 식당·카페·소매점 사장님을 위한 직원·근태·스케줄·급여·근로계약 통합 관리 서비스
- 핵심 가치: 직원 등록부터 근무표, 출퇴근, 급여 마감까지 매장의 하루를 하나의 흐름으로 연결
- 대상 사용자: 소규모 매장 사장님(의사결정자), 매니저, 직원
- 성격: 제품 소개·요금·시작가이드·데이터/권한 안내 중심의 정보성 마케팅 사이트 (판매 준비 단계)
- 메인 카피: "직원 출근부터 월급 정리까지, 척척."
  - 설명: "앱 설치 없이 휴대폰으로 여세요. 오늘 누가 일하는지, 이번 달 급여는 얼마인지 한곳에서 확인해요."
  - 주 CTA: "무료로 시작하기"(→ 운영 앱 /demo) / 보조 CTA: "화면 먼저 보기"(→ #product-demo)
  - 브랜드 심볼: 단정한 이중 체크 표시(로고·파비콘). 캐릭터: 공식 캐릭터 "척척이"(초록 앞치마·크림 몸체·라임 체크)
- 사용자 기준: 작은 가게 사장님(60~70대 포함)이 혼자 이해하고, 바쁜 40대 사장님도 설치 없이 시작
  - 본문 18px 이상, 보조 문구 16px 이상, 버튼 높이 56px 이상, 충분한 명암비
  - 쉬운 표현 사용: 근태→출퇴근, 대시보드→우리 가게 한눈에, 온보딩→시작하기
  - 작은 회색 글씨·영문만 있는 문구·아이콘만 있는 버튼 지양 (고령자에게 유아적인 문구 금지)
- 중요 원칙:
  - 검증되지 않은 고객사 로고·후기·수상·절감률·카운트다운 등 허위 요소 금지
  - PG 미연결 상태이므로 구매·카드 입력·결제 성공 화면 생성 금지
  - 법정수당 완전 자동산정/공인 인증서·법적 효력 보장/급여 송금/세금 신고/카카오 로그인/GPS 인증/ERP 연동/인증메일·비밀번호 찾기·계약 사본 이메일 발송/실결제는 "제공"으로 주장 금지
  - 근로계약은 앱 /contracts에서 양측 확인·서명과 사본 관리로 표기하고, "공인 인증서·법적 효력 보장"으로 표현 금지 (이메일 인증·발송은 회사 도메인·발송 서비스 연결 전이므로 완전 이용·발송 완료로 홍보 금지)

## 3. Core Features (사이트 관점)
- [x] 로그인·회원가입 진입 분리: /start에서 사장님(회원가입·로그인) / 직원(가입·합류·로그인) 두 카드로 안내하고 모바일에서는 세로 배치. 회원가입·로그인은 이메일·비밀번호로 진행함을 명시. 직원은 이메일 계정 만들기→가게 코드 확인→이름·연락처·주소·첫 근무일 입력→사장님이 미리 설정한 근로계약 초안 확인→가입 신청→사장님 승인 대기→수락 후 본인 화면. 사장님은 직원 가입 신청 관리에서 매장별 조건을 설정하고 신청 정보와 계약을 검토해 수락. 역할 선택만으로 권한이 생기지 않음을 명시. 체험·"무료로 시작하기" CTA는 운영 앱 /demo, "내 가게 열기"는 운영 앱 /start로 직접 연결(사이트 내 /try·/start 페이지는 안내용으로 유지)
- [x] 런칭 준비 배너 (가입 없이 화면부터 체험·카드 등록 없이)
- [x] 홈 순서: 한 줄 효용 헤드라인+CTA → 직접 눌러보는 제품 화면 → 어떻게 시작하나요 3단계 → 이용 요금 → 질문 → 최종 CTA (반복 슬로건·중복 설명 제거로 길이 축소)
- [x] 제품 시연(요약→상세→복귀): 기본 화면은 “우리 가게” 홈 요약 — 가장 큰 카드 “이번 달 예상 급여” 가상 266,000원 · “입력된 근무·수당·공제 기준 · 검토 전” · 주 버튼 “급여 자세히 보기”, 아래 “오늘 출근 4명 · 지금 근무 1명”(→ 출퇴근 상세, 상세 목록도 4명과 일치)과 그 아래 작은 링크 “오늘 근무표 보기”(→ 근무표 상세), “확인할 일 4건”은 근무표로 가지 않고 직원정보 확인 4명 예시 목록을 접고 편다. 요약 카드 캐릭터는 새 공식 안내 자세 이미지(72px · 밝은 크림 배경 · object-contain · 금액 안 가림)로 교체하고, 날짜는 9월 23일 수요일(예시)로 통일, 급여 상세 합계도 266,000원으로 일치(합계 직원별 실수령 합 = 266,000원). 합성 예시 라벨 유지(실제 송금·저장 아님). 출퇴근 전체 표·통계·환영 배너는 기본 화면에 함께 쌓지 않고, 요약에서 한 동작을 눌렀을 때만 기존 상세(일간/주간 타임라인·급여 표)를 보여주고 “요약으로 돌아가기” 제공. 자동 전환 없음. 큰 전환 버튼 3개와 상세 표를 한 화면에 동시에 쌓지 않음
- [x] 브랜드 제품체험(BrandExperience): 홈·제품 페이지에서 동일 컴포넌트 사용. 딥그린·라임·크림 + 척척이 캐릭터 유지

- [x] 모션 설정: 제품시연 본문에서 조작을 빼고 푸터의 작은 “글씨 크게 보기”·“움직임 줄이기” 토글 두 개로만 제공(48px 터치). 움직임 설정은 전역 동기화되어 히어로 영상과 제품 장식 모션에 함께 적용되고 끈 상태 저장. 글씨 크기는 보통 크기를 기본으로 하고 사이트 전체에 저장된 상태로 반영
