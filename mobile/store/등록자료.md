## 2. 긴 설명 (구글 4,000자 · 애플 설명)

```
작은 가게 사장님을 위한 직원 관리 앱, 척척사장.
직원 등록부터 근무표, 출퇴근, 급여 계산, 명세서, 근로계약서까지 휴대폰 하나로 정리해요.

■ 근무표
- 주간·월간 근무표를 손가락으로 끌어 옮기고 복사
- 시간대별 필요 인원, 주 15시간·52시간·휴게시간 경고
- 근무표를 공개하면 직원에게 바로 알림, 누가 확인했는지 표시
- 대타·교대 요청을 직원끼리 구하고 사장님은 승인만

■ 출퇴근
- 매장 QR을 찍어 출근·퇴근·휴게 기록
- 지각·조퇴·미출근·퇴근 누락을 자동으로 확인하고 알림
- 출근 위치 확인(선택), 오프라인일 때 임시 저장

■ 급여
- 시급·일급·월급, 주휴수당, 연장·야간·휴일 가산, 4대보험·소득세 공제 자동 계산
- 임금명세서 발송과 열람 확인, 임금대장, 은행 대량이체 파일
- 직원은 "내 급여 왜 이래요?"로 항목별 설명을 바로 확인

■ 서류
- 표준 근로계약서 작성과 사장님·직원 전자서명
- 재직·경력증명서, 보건증·계약 만료 알림, 근로감독 대비 서류 묶음

■ 매장 운영
- 공지(읽음 확인·댓글·투표), 매뉴얼, 오픈·마감 체크리스트, 인수인계
- 휴가 신청·승인, 연차 자동 계산
- 척척 비서에게 "오늘 누가 일해?"처럼 물어보기

■ 직원 화면
- 내 근무표, 출퇴근, 이번 달 예상 급여, 명세서·계약서를 한곳에서
- 영어·중국어·베트남어 화면 지원

■ 이용 안내
- 사장님은 가입 후 30일 무료 체험(카드 등록 없음, 자동 결제 없음)
- 직원은 무료
- 계산 결과는 참고 자료이며 법률·세무 자문이 아니에요.

문의: 앱 안 '문의하기' 또는 https://chukchukapp.kr/support
```

## 5. 개인정보 답변

### 구글 플레이 — 데이터 보안(Data safety)
- 데이터 수집: 예 / 공유: 아니요(처리 위탁은 '공유' 아님) / 전송 중 암호화: 예 / 삭제 요청 방법: 앱 안 회원 탈퇴 + https://chukchukapp.kr/privacy-request
- 수집 항목과 목적(모두 '앱 기능', 선택 여부 표시)
  - 개인 정보: 이름, 이메일, 전화번호(필수), 주소(선택) — 계정·직원 관리
  - 금융 정보: 급여·계좌 정보(선택, 사장님이 입력) — 급여 계산·이체 파일
  - 위치: 대략적·정확한 위치(선택, 출근 위치 확인을 켠 매장만, 좌표 저장 안 함) — 앱 기능
  - 사진: 사진(선택) — 체크리스트·공지·신고 첨부
  - 앱 활동: 앱 내 기록(출퇴근·근무·공지 읽음) — 앱 기능
  - 앱 정보 및 성능: 오류 로그(개인정보 지움) — 분석·문제 해결
  - 기기 ID: 알림 토큰 — 알림 보내기
- 광고 ID: 쓰지 않음(앱 안에서는 광고 측정 끔)

### 애플 — 앱 개인정보(App Privacy)
- 추적(Tracking): 아니요
- 연결된 데이터(사용자 식별 가능): 연락처 정보(이름·이메일·전화·주소), 금융 정보(기타 금융 정보: 급여), 위치(정확한 위치, 앱 기능), 사용자 콘텐츠(사진·기타), 식별자(사용자 ID), 사용 데이터(제품 상호작용), 진단(오류 데이터) — 모두 '앱 기능'(진단은 '분석')
- 데이터는 광고에 쓰지 않음
